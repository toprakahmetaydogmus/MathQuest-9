## 🎯 1. Project Overview
**MathQuest-9** transforms the standard 9th-grade high school mathematics curriculum (Logic, Sets, Equations, Inequalities, Functions, and Geometry) into an engaging, gamified RPG-style learning platform designed to make math intuitive, competitive, and fun.

### Key Features:
- **RPG Progression System:** Earn XP, level up, unlock badges, and acquire achievement titles as you solve math problems.
- **Interactive Problem Solver:** Step-by-step mathematical reasoning and visual graph representations.
- **Leaderboards & Timed Challenges:** Real-time ranking competitions and daily quests.
- **Responsive Dark/Light Mode:** Designed with smooth CSS glassmorphic animations and mobile responsiveness.
